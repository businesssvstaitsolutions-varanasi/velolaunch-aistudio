1. Overview & Privacy Architecture

Apex Tornado is an open, high-performance browser cleaner, memory maintenance agent, and tab reloading automation extension engineered by VeloLaunch in collaboration with Smart Vista IT Solutions.

We believe that browser performance tools should never come at the cost of personal privacy. Unlike commercial browser utility software that collects browsing habits, telemetry IDs, or search clicks, Apex Tornado is architected from line one as a 100% client-side application.

Key Guarantee: Apex Tornado does not maintain external analytics servers, tracking databases, user registries, or background logging services. Everything executes locally inside your browser sandbox.

2. Data We Do Not Collect

We explicitly state what information is NEVER collected, logged, recorded, transmitted, sold, or shared by Apex Tornado:

  • No Browsing History: We do not track, record, or transmit the websites you visit, URLs you type, or search queries you perform.
  • No Personal Identifiers: We do not ask for or collect names, email addresses, phone numbers, IP addresses, or device fingerprints.
  • No User Accounts: Apex Tornado has no login systems, account portals, or authentication servers.
  • No Cookie Uploads: When you manage or purge cookies, operations occur strictly via standard Chromium browser APIs directly on your computer. Cookies are never inspected by remote parties.
  • No Keystrokes or Form Content: The extension does not inspect webpage content, form inputs, passwords, or clipboard text.
  • No Advertising IDs: We do not integrate with Google AdSense, ad networks, tracking pixels, or third-party marketing SDKs.

3. Chrome Permissions & Technical Justification

To perform browser cleaning, tab reload scheduling, and memory optimization, Apex Tornado requests specific permissions defined under Google's Manifest V3 standard. Under the principle of Single Purpose compliance, each permission is restricted strictly to its core functional purpose:

Permission API Scope Exact Purpose Network Exposure
browsingData Data Cleansing Allows user-initiated or rule-scheduled clearing of cache, downloads, cookies, local storage, indexedDB, and temporary service workers. None (Local)
cookies Cookie Management Allows granular cookie inspection and selective deletion, protecting user-whitelisted domains from logout. None (Local)
tabs Tab Automation Enables automated background reloading for user-selected monitoring tabs and URL domain matching for protected whitelists. None (Local)
storage Local Persistence Saves user settings, reload schedules, whitelist domains, and cleaning preferences locally via chrome.storage.local. None (Local)
alarms Event Scheduling Wakes the Manifest V3 background service worker at user-defined intervals to execute reload timers or maintenance tasks without keeping CPU idle. None (Local)

Host Permissions: In order for Chromium's cookie management APIs to view and remove cookies for specific websites as requested by the user, host access is required. This access is never used to inject malicious scripts, alter web page appearance, or extract page contents.

4. Local Storage & Configuration Retention

All configuration data you create within Apex Tornado is stored strictly within your browser's private local storage partition:

  • Protected Domains Whitelist: Domains you choose to safeguard (e.g. github.com, mail.google.com) to prevent accidental cookie eviction.
  • Tab Reload Schedules: Tab IDs, targets, and time intervals you configure for automated dashboard refreshes.
  • Clean Profiles & Rules: Selected cleanup categories (e.g., cache only, downloads history, service workers).
  • UI Preferences: Dark / light theme choices and notification display settings.

Export / Import Functionality: When you use the Backup feature in Apex Tornado, your settings are serialized into a clean, human-readable JSON file (apex-tornado-config.json) generated on-the-fly directly in your browser. No files are uploaded to any server.

5. Cookies & Cache Purging Safeguards

When you trigger a cache purge or cookie cleanup in Apex Tornado:

  1. The extension checks your active whitelist to exclude protected session tokens.
  2. The Chromium chrome.browsingData.remove or chrome.cookies.remove API is invoked natively by the browser kernel.
  3. Data is permanently deleted from the browser cache directories on your hard drive.
  4. Apex Tornado does not keep audit logs, backups, or forensic copies of deleted files or cookies.

6. Zero Telemetry & Third-Party Code Policy

Our extension source code is clean, transparent, and self-contained:

  • Zero Tracking SDKs: We do not include Google Analytics, Sentry, Mixpanel, Amplitude, Segment, or Facebook Pixel.
  • No Remote Code Injection: Manifest V3 strictly prohibits loading remote scripts at runtime. All extension JavaScript is bundled directly within the package inspected and approved by the Chrome Web Store.
  • Auditable Code: Anyone can inspect the manifest and scripts by unzipping the extension package or reviewing our open-source codebase.

7. Regulatory Compliance & Standards

Google Chrome Web Store Limited Use Disclosure

Apex Tornado adheres to the Chrome Web Store Developer Program Policies, including the Limited Use requirements:

  • Use of permissions is limited strictly to providing or improving the user-facing features of the browser cleaner.
  • Data accessed through Chromium APIs is never transferred or sold to third parties, data brokers, or advertising platforms.
  • Data accessed is never used for creditworthiness, lending, profiling, or targeted advertisements.

GDPR Compliance (EU Users)

Under the General Data Protection Regulation (GDPR), we practice true Data Minimization and Privacy by Design. Because no personal data is collected or transmitted to external controllers, no data processing contracts or user consent banners are required.

CCPA / CPRA Compliance (California Users)

Under the California Consumer Privacy Act (CCPA) and CPRA, we declare: We do not sell, rent, or share personal consumer information.

8. User Rights & Complete Data Deletion

You maintain full sovereignty over your environment at all times:

  • Resetting Settings: You can clear all saved whitelists, rules, and reload schedules instantly from the Settings & Backup tab using the "Reset to Defaults" action.
  • Uninstalling the Extension: Right-clicking the Apex Tornado extension icon and selecting "Remove from Chrome..." immediately and permanently destroys all local storage partitions, configuration records, and cached data maintained by the extension.
